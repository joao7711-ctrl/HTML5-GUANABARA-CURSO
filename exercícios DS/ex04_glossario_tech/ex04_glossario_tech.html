Glossario Tech

HTTP/HTTPS
É o protocolo básico da web para transferência de dados. O HTTP é o padrão, e o HTTPS é a versão segura (com cadeado), que criptografa as informações entre o navegador e o servidor [1, 2].
Front-end
É a "cara" do software. Tudo o que o usuário vê e interage (botões, cores, fontes, menus) é responsabilidade do desenvolvedor front-end [3].
Back-end
É o "motor" que roda por trás. Ele lida com o banco de dados, a lógica de negócio, segurança e o processamento de informações que o usuário não vê diretamente [3].
API
Pense na API como um "garçom". O cliente (Front-end) faz um pedido, a API leva esse pedido até a cozinha (Back-end) e traz a resposta de volta. É o que permite que sistemas diferentes conversem entre si.
Responsividade
É a capacidade de um site ou aplicativo de se adaptar automaticamente ao tamanho da tela em que está sendo exibido, seja em um monitor gigante, num tablet ou em um smartphone, mantendo a usabilidade.
Framework
É um conjunto de ferramentas, bibliotecas e padrões já prontos para facilitar o desenvolvimento. Em vez de construir uma casa do zero, tijolo por tijolo, usar um framework é como usar peças pré-moldadas para acelerar o processo e manter a organização.
